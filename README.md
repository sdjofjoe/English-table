# 六级手账 · 70天备考监督

一本陪你备考英语六级（CET-6）的手账，不是冷冰冰的工具。

纯前端单机 Web 应用（PWA），无需账号、无需服务器，所有数据只存在你自己的浏览器本地。

## 功能

- **70 天计划引擎** —— Day 1–15 阶段A（每天 50 新词 + 1 篇阅读），Day 16 起自动切阶段B（新词降 30 + 听力三步法），早晚任务清单可勾选
- **照片打卡监督** —— 每天 22:00 前上传两张照片（背单词截图 + 错题标注），缺一张记空页（断卡）
- **打卡盖章** —— 打卡成功盖砖红圆章 + 弹出「同桌的小纸条」鼓励语（带你的名字、结合当天数据、不重样）；里程碑（3/7/15/30 天）有号角音效
- **手写单词 OCR** —— 拍下平板手写的单词，点「识别」按钮本地识别入词库（Tesseract.js，数据不出本机）
- **三天抽查** —— 默写 + 选择题混合，错的词自动滚进第二天复习清单；不及格不算断卡
- **记忆曲线复习** —— 按艾宾浩斯间隔（1/2/4/7/15/30 天）自动排复习清单
- **数据统计** —— 70 天打卡热图、连续天数、里程碑徽章、阅读错题趋势、错因分布、抽查成绩曲线
- **手账风界面** —— 米白纸面、墨绿/砖红/焦糖配色、霞鹜文楷手写体、便签卡片与胶带装饰
- **音效** —— 勾选、盖章、抽查对错等场景的合成音效，可在设置中关闭
- **留言风格可切换** —— 同桌（温柔但具体）/ 课代表（严格）/ 损友（毒舌）

## 使用

### 方式一：直接打开（本机）

用 Chrome / Edge 打开 `index.html` 即可，但建议用本地服务器（Service Worker / PWA 安装需要 http 环境）：

```bash
node server.cjs
# 打开 http://localhost:8642
```

或双击 `start-cet6.bat`（Windows）。

### 方式二：部署到 GitHub Pages（支持手机）

1. Fork 或上传本仓库到你的 GitHub
2. 仓库 Settings → Pages → Source 选 `main` 分支 / 根目录
3. 访问 `https://<你的用户名>.github.io/<仓库名>/`
4. 手机浏览器打开该地址 → 菜单 →「添加到主屏幕」，即获得可离线使用的 App 图标

## 数据说明（重要）

- 所有数据（打卡、词库、统计）存在浏览器 IndexedDB 中，**不联网、不上传、不跨设备同步**
- 换设备 / 清理浏览器数据前，先在「设置 → 导出全部数据」备份 JSON，新设备「导入数据」恢复
- OCR 引擎（Tesseract.js）与手写字体首次使用需联网加载，之后可离线

## 技术栈

原生 HTML / CSS / JavaScript（ES Modules），IndexedDB 存储，Service Worker + Web App Manifest（PWA），Tesseract.js（OCR），Web Audio API（音效），无任何框架、无构建步骤。
